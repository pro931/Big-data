How it was built

  1. Loaded Advertising.csv into a Spark DataFrame with schema inference and explored it with describe().
  2. Combined TV, radio and newspaper into one feature vector with Vectors.dense; sales is the label.
  3. Split the data randomly: 60% for training, 40% for testing.
  4. Built an MLlib Pipeline with a VectorIndexer and LinearRegression, and fit it on the training set.
  5. Read coefficients, standard errors, t-values and p-values from the model summary.
  6. Evaluated on the test set with RegressionEvaluator (RMSE) and R².
Built by Rimas Abdulrhman · Data Analyst. Dataset: the public Advertising dataset (200 markets) from An Introduction to Statistical Learning.
